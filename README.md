# **PODNO: Proper Orthogonal Decomposition Neural Operators**

We introduce **Proper Orthogonal Decomposition Neural Operators (PODNO)** for solving partial differential equations (PDEs) dominated by high-frequency components with high computational efficiency.  
This repository provides the official implementation for our paper:  
📄 [https://arxiv.org/abs/2504.18513](https://arxiv.org/abs/2504.18513)

---

## 💬 Remarks

### **— Generation of Snapshots for Time-Dependent Equations**

There are three possible strategies for generating snapshots for time-dependent PDEs:

- Case 1: Include the initial condition and final solution
  
$$
X_{\text{type 1}} = [u_0, u_{N_T}],
$$  
- Case 2: Include the solutions at each time step
  
$$
X_{\text{type 2}} = [u_0, u_1, \dots, u_{N_T}],
$$  
- Case 3: Include the solutions at each time step and their differences

$$
X_{\text{type 3}} = [u_0, u_1, \dots, u_{N_T},\ u_1 - u_0, u_2 - u_1, \dots, u_{N_T} - u_{N_T-1}].
$$

- **Efficient approach (used in the paper):** take snapshots only from the *initial condition* and *final solution* as Case 1.  
- **Higher-accuracy alternative:** if full temporal evolution is available, include intermediate time steps as additional snapshots as Case 2.

---

### **— Generation of POD Basis**

There are three ways to calculate the POD basis:

- SVD of the covariance matrix

$$
C = XX^T = H \Sigma S^2H^T
$$

- SVD of the snapshot matrix

$$
X = H \Sigma S^T
$$

- Since C is symmetric, one may compute its eigen-decomposition directly.
